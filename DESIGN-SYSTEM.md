# SpendWise – UI Design System

## 1. Introduction

SpendWise is a personal finance management application that helps users manage monthly budgets, track daily expenses, monitor spending patterns, and achieve savings goals.

This document defines the visual design standards used throughout SpendWise to maintain a consistent, attractive, and user-friendly interface.

## 2. Colour Palette

SpendWise uses a purple and lavender colour theme to provide a modern and clean appearance.

| Colour Type | Hex Code | Usage |
|---|---|---|
| Primary | #70549C | Main buttons, links and highlights |
| Secondary | #513875 | Hover effects and strong accents |
| Background | #F5F2F8 | Main page background |
| Text | #302541 | Headings and primary text |
| Accent | #D9C9ED | Progress bars and highlights |
| Card Background | #E6DCF1 | Cards and content sections |
| Border | #CDBDE0 | Card and input borders |
| Muted Text | #756987 | Secondary information |
| Success | #16A34A | Successful actions and completed goals |
| Error | #DC2626 | Error messages and delete actions |

## 3. Typography

**Font Family:** Inter / Sans-serif

A clean and readable sans-serif font is used throughout the application.

| Element | Font Size | Font Weight |
|---|---|---|
| H1 – Main Heading | 32px | Bold (700) |
| H2 – Section Heading | 24px | Semi Bold (600) |
| H3 – Card Heading | 18px | Semi Bold (600) |
| Body Text | 16px | Regular (400) |
| Button Text | 14px | Semi Bold (600) |
| Secondary Text | 14px | Regular (400) |
| Small Labels | 12px | Medium (500) |

## 4. UI Components

The following reusable components are used in SpendWise.

| Component | Purpose |
|---|---|
| Navbar | Navigation between Dashboard, Expenses and Savings |
| BudgetCard | Displays budget, expenses, remaining budget and savings |
| SpendingChart | Visualizes category-wise expenses |
| ExpenseForm | Allows users to add expenses |
| ExpensesList | Displays, edits and deletes expenses |
| SavingsSummary | Displays monthly savings and savings targets |
| SavingsGoalCard | Displays individual savings goals |
| SavingsGoalForm | Creates new savings goals |
| AddSavingsModal | Adds contributions to savings goals |
| Input Fields | Accept budget, expense and savings details |
| Buttons | Perform actions such as add, edit and delete |
| Progress Bar | Displays budget usage and savings progress |
| Empty State | Displays messages when no records are available |
| Modal | Displays forms and confirmation actions |

## 5. Layout and Spacing

- Maintain consistent spacing between components.
- Use rounded corners for cards, buttons and input fields.
- Keep content properly aligned.
- Use sufficient padding inside cards and sections.
- Maintain a clean and organized dashboard layout.
- Support mobile, tablet and desktop screen sizes.

## 6. Design Principles

1. **Simplicity:** Keep the interface clean and easy to understand.
2. **Consistency:** Use the same colours, fonts and component styles across pages.
3. **Accessibility:** Maintain readable text and clear labels.
4. **Responsiveness:** Support different screen sizes.
5. **Usability:** Make financial information easy to access and understand.

## 7. Conclusion

The SpendWise UI Design System establishes consistent visual standards for the application. Its purple and lavender colour palette, readable typography, reusable components and responsive layouts provide a simple and user-friendly personal finance management experience.
